# Checked Body IR lowering

This compiler-ring Loaf reads the canonical types from `incan_semantics_core` through Rust interop. `validate_module` checks every retained declaration and body using the module's stage-2a identity validators before a consumer trusts their identities. The caller receives a shared reference to the same Rust type; no wire format or duplicate Incan declaration defines the Body IR facts.

`lower_module(module: &BodyIrModule, source: str, file: str) -> Result[Plan, str]` constructs `incan_mir_plan` data directly from checked scalar locals, operands, assignments, structured control flow, and canonical same-module calls. Integer addition, subtraction, multiplication, and negation have explicit overflow assertions. Floor division and remainder use the canonical `incan_std_core::num` helpers. Each call has a separate cleanup exit. The original source is used only to map retained byte offsets to diagnostic coordinates.

Formatting uses exact arrays and borrowed slices passed to `incan_std_core::strings::fstring`; an authored Incan runtime supplies monomorphic scalar display, printing, and range validation. Initialized string owners receive normal drops and per-call cleanup chains. Conditional ownership merges that require drop flags are refused by name. String parameters, returns, cloning, and registered text helpers use the same owner tracking. Native corpus validation records which fixtures are admitted; admission remains incomplete. Constructs outside the implemented slice return a named refusal; this Loaf never falls back to generated Rust. A successful library bake proves that its Incan implementation compiles, while the source-to-native integration and corpus tests establish executable coverage separately.

Condition assertions preserve the legacy failure payload and exit behavior. Assertion messages are evaluated only on the failure path retained in Body IR. Same-module function calls evaluate omitted scalar or string defaults from their declaration-owned computations, with local storage isolated from the caller; supplied arguments bypass those computations. Pattern and raises assertions and defaulted parameter representations outside that scalar/string profile remain named refusals.

Ordinary unions over admitted scalar and source nominal member types reuse the source-enum plan and adapter. `unions.incn` normalizes members by their legacy Rust payload spelling, preserves the generated union name and `V0`, `V1`, … variant order, and injects payloads at assignment, argument, and return boundaries. Checker-selected member projections and constructor-pattern target types carry narrowing facts in Body IR. Concrete member matches and primitive `isinstance` checks read the enum discriminant; subset reconstruction, optional unions, union display, and unions containing unadmitted payload types remain named refusals.

The Rust caller boundary admits only `BodyIrModule` and `StatementKind` from the canonical semantics-core path, including public Rust-backed aliases and shared references. The caller baker checks that the host and provider declare the same canonical local package and dependency configuration, then recompiles the caller against the host’s exact semantics-core artifact. The artifact digest enters the caller recipe and receipt, because matching source and version alone cannot establish Rust type identity after feature unification. Other Rust-backed exports are refused. The plan's public data types are re-exported under their original names; caller validation follows their declaring Loaf's checked field and variant contracts rather than admitting opaque aliases.

Text helpers select the canonical runtime for Unicode scalar length, case conversion, stripping, replacement, containment, splitting, and joining. Omitted split separators preserve the original text as one piece. Scalar truthiness, checked integer absolute value and sum, homogeneous list sorting and concatenation, and same-carrier exponentiation use authored native-runtime entry points retaining legacy emission. Unsupported element representations and JSON serialization remain named refusals. Source boolean short-circuiting is retained as Body IR branches before operands are flattened; compiler-generated boolean combinations operate only on already evaluated boolean operands.
