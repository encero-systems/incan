# Interop deployment commands

Dev.8's CLI provides no `incan inspect interop-plan`, `incan oven interop bake` or `incan oven interop stage` command.

C header declarations are accepted through `[interop.c]` in [Project configuration](project_configuration.md#interopc). Language binding contracts are specified in [`std.interop`](../../language/reference/stdlib/interop.md).
