# Release 0.6

Incan 0.6 is under development. This page lists changes assigned to the release without presenting unreleased Alpha
work as generally available or complete.

## Tooling

- **Oven Alpha (experimental)**: `incan oven` establishes receipt-bound, direct-`rustc` build, test, and binary-run consumer seams that never launch Cargo. Typed release and compiler-suite envelopes contain content-addressed `.loaf` directories with verified plans and artifacts. One hidden `legacy_cargo bake-loafs` call prepares or exactly reuses the supported envelope and its bounded compiler-suite store; ordinary `incan build`, `incan test`, and `incan run` consume compatible Loafs or stop with actionable toolchain/envelope guidance, never with a Cargo fallback. Storage policy reports logical artifacts, physical allocation, raw disk use, reclaimability, and active leases separately, refuses oversized domains, and protects live consumers from pruning. The repository suite runs through the same guarded Oven runner and reports both case and green/red root aggregates. General Rust workspace compatibility and ecosystem bake-offs remain later Oven work (#1005, #975).

- **Generated-build transition**: The bounded generated-Cargo cache remains historical 0.5 architecture and explicit publisher compatibility evidence. Oven Alpha replaces it as the maintained normal backend only for the documented 0.6 envelope; unsupported dependency and workspace shapes fail closed rather than restoring a Cargo fallback (#876, #877, #925, #1005).
